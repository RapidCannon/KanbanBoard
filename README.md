# 📒 KanbanBoard

This project is a interactive kanban board. A visual management tool that helps people manage workflows, and order out what they want to accomplish. Using lists with cards to visualize tasks, moving them along your lists as you complete them. Using these boards can greatly help people focus and complete tasks without forgetting about other tasks.

# 🎓 Technologies

- HTML
- CSS
- JAVASCRIPT

# 📜 Features

- Moving tasks with your mouse to other lists with the HTML Drag and Drop API.
- Add more tasks with a click of a button

# 🎏 What I Could Improve

- A removal Button to each Task, Allowing people to remove tasks once they are complete or if there is a typo
- A way to add more Lists or a way to customize them for each personal user's needs
- Add a description option to tasks so people can add more info to each task
- Use LocalStorage so people can close the page and come back to it at another time while keeping their tasks
